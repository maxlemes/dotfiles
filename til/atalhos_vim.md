
# Meus Atalhos do Vim

## 📖 Navegação

| Atalho            | Ação                                                      |
|-------------------|-----------------------------------------------------------|
| `h`               | Mover o cursor para a esquerda (1 caractere)              |
| `j`               | Mover o cursor para baixo (1 linha)                       |
| `k`               | Mover o cursor para cima (1 linha)                        |
| `l`               | Mover o cursor para a direita (1 caractere)               |
| `w`               | Avançar uma palavra (no modo normal)                      |
| `b`               | Voltar uma palavra (no modo normal)                       |
| `gg`              | Ir para o início do arquivo                               |
| `G`               | Ir para o final do arquivo                                |
| `0`               | Ir para o início da linha atual                           |
| `$`               | Ir para o final da linha atual                            |
| `Ctrl + f`        | Avançar uma tela (página)                                 |
| `Ctrl + b`        | Voltar uma tela (página)                                  |
| `Ctrl + d`        | Avançar meio da tela                                      |
| `Ctrl + u`        | Voltar meio da tela                                       |
| `fx`              | Mover o cursor até o próximo `x` (caractere) na linha     |
| `F`x              | Mover o cursor até o anterior `x` na linha                |

## ✨ Edição

| Atalho            | Ação                                                      |
|-------------------|-----------------------------------------------------------|
| `i`               | Entrar no modo de inserção antes do cursor                |
| `I`               | Entrar no modo de inserção no início da linha             |
| `a`               | Entrar no modo de inserção após o cursor                  |
| `A`               | Entrar no modo de inserção no final da linha              |
| `o`               | Abrir uma nova linha abaixo da linha atual                |
| `O`               | Abrir uma nova linha acima da linha atual                 |
| `Esc`             | Sair do modo de inserção e voltar ao modo normal          |
| `u`               | Desfazer a última ação                                    |
| `Ctrl + r`        | Refazer a última ação desfeita                            |
| `x`               | Apagar o caractere sob o cursor                           |
| `dd`              | Apagar a linha atual                                      |
| `yy`              | Copiar (yank) a linha atual                               |
| `p`               | Colar o conteúdo copiado abaixo da linha atual            |
| `P`               | Colar o conteúdo copiado acima da linha atual             |

## 🔍 Pesquisa

| Atalho            | Ação                                                      |
|-------------------|-----------------------------------------------------------|
| `/texto`          | Pesquisar por "texto" no arquivo                          |
| `n`               | Ir para a próxima ocorrência de pesquisa                  |
| `N`               | Ir para a ocorrência anterior de pesquisa                 |

## 🔧 Manipulação de Janelas

| Atalho            | Ação                                                      |
|-------------------|-----------------------------------------------------------|
| `:split`          | Dividir a janela horizontalmente                          |
| `:vsplit`         | Dividir a janela verticalmente                            |
| `Ctrl + w, h`     | Mover para a janela à esquerda                            |
| `Ctrl + w, j`     | Mover para a janela abaixo                                |
| `Ctrl + w, k`     | Mover para a janela acima                                 |
| `Ctrl + w, l`     | Mover para a janela à direita                             |

## 💡 Outros

| Atalho            | Ação                                                      |
|-------------------|-----------------------------------------------------------|
| `:w`              | Salvar o arquivo                                          |
| `:q`              | Sair do Vim                                               |
| `:wq`             | Salvar e sair do Vim                                      |
| `:x`              | Salvar e sair do Vim (mesma ação que `:wq`)               |
| `:q!`             | Sair do Vim sem salvar mudanças                           |
| `:e <file>`       | Abrir o arquivo `<file>`                                  |
| `:w <file>`       | Salvar o arquivo como `<file>`                            |
