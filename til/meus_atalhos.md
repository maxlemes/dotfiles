
### Atalhos para mudar o layout do dwm

| Atalho        | Ação                    |
|---------------|-------------------------|
| MOD + t       | tile (layout padrão)    |
| MOD + f       | floating                |
| MOD + m       | monocle                 |
| MOD + u       | centeredmaster          |
| MOD + o       | centeredfloatingmaster  |
| MOD + space   | alterna entre layouts   |

### Atalhos que mudam o número de janelas na área mestre

| Atalho        | Ação                                       |
|---------------|--------------------------------------------|
| MOD + i       | aumenta o número de janelas na área mestre |
| MOD + d       | diminui o número de janelas na área mestre |

### Atalho para alterar o tamanho da área mestre

| Atalho        | Ação                             |
|---------------|----------------------------------|
| MOD + h       | diminui o tamanho da área mestre |
| MOD + l       | aumenta o tamanho da área mestre |

### Atalhos para o fzf

| Atalho        | Ação                                  |
|---------------|---------------------------------------|
| Ctrl + R      | Histórico de comandos com preview     |
| Ctrl + T      | Fuzzy find de arquivos (inserir path) |

### Atalhos para o Sublime Text

| Atalho                  | Ação                           |
|-------------------------|--------------------------------|
| Ctrl + Tab              | Alternar para a aba à direita  |
| Ctrl + Shift + Tab      | Alternar para a aba à esquerda |
| Alt + <número da aba>   | Vai para uma aba específica    |
